Al guardar una actividad, se puede actualizar un archivo JSON en tu repositorio con todas las actividades y el agrupado por semanas. Necesitas un Personal Access Token con permiso repo (repositorio privado) o al menos acceso al repo público. El token se guarda solo en este navegador; no lo uses en equipos compartidos.
