# Base de Datos 2 · Actividades semanales (UPLA)

Página web simple (HTML + CSS + JavaScript) para registrar y compartir las actividades semanales de un semestre.

## Cómo abrir

1. Abre `index.html` (doble clic).
2. Para agregar/editar, presiona **Agregar actividad** (se abre `add.html` en otra pestaña).
3. Registra tus semanas y actividades durante el semestre.

## Dónde se guardan los datos

Se guardan en tu navegador usando **localStorage**.  
Si cambias de PC/navegador, tendrás que volver a registrar las actividades en ese equipo.

## Archivo Java (opcional)

El navegador **no ejecuta Java**.  
Incluí `ActividadExporter.java` solo como utilidad para generar un JSON de ejemplo para importar en la web.
